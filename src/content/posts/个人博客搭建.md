# 个人博客搭建

## 配置DNS

- 在 DNS 控制台添加 A 记录。
- 将自己的域名解析到云服务器公网 IPv4 地址。

## 两种部署方式

### 一、云服务器运行项目

- 在服务器上git项目，安装 Node.js、pnpm 和项目依赖
- 执行 `pnpm build`构建项目，运行
- 用 nginx 把服务器的默认端口（http是80，https是443）转发到项目运行的5174端口

### 二、本地构建+服务器静态托管

云服务器内存较小，不适合在服务器上执行资源消耗较大的构建过程，采用静态托管

- 本地通过 Git 获取项目源码，使用 `pnpm build` 构建出 HTML、CSS、JavaScript 等静态文件
- 将生成的 `dist` 目录内容上传到服务器，配置Nginx 静态托管
- 用户访问域名时，浏览器先通过 DNS 获取服务器 IP，然后连接服务器的 Nginx。Nginx 直接读取静态文件并返回给浏览器。
